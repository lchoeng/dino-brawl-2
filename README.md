# Dino Brawl II

A 2D Street Fighter–style game with six dino-costume fighters:

| Fighter | Special |
|---|---|
| Linus | Fire Breath |
| Wesley | Tail Spin |
| Mosasaurus | Belly Flop |
| T-Rex | Chomp Attack |
| Ankylosaurus | Tail Whip |
| D-Rex | Head Butt |

Open `index.html` in a browser (or turn on GitHub Pages) to play.

## Controls
- **Phone/tablet:** on-screen buttons (turn sideways for a bigger screen)
- **Player 1:** A / D move · W jump · J punch · K slam · L special
- **Player 2:** ← / → move · ↑ jump · `,` punch · `.` slam · `/` special
- Hold the direction away from your opponent to block. Best of 3 rounds. Esc returns to the menu.

Linus and Wesley are cut from the original character video (`L.webp`, `W.webp`); the other four are drawn in code (`puppets.js`).
